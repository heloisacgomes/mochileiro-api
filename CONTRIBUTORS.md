# Autoria e contribuições

O Mochileiro API é um projeto individual desenvolvido por
Heloísa Gomes como parte do Projeto Final de Full Cycle.

**Desenvolvedora:** Heloísa Gomes  
**GitHub:** [@heloisacgomes](https://github.com/heloisacgomes)

O projeto contempla implementação, configuração,
integração com IA, testes, documentação e validação
das funcionalidades.

Durante o desenvolvimento, foram utilizadas ferramentas
de inteligência artificial como apoio técnico, conforme
descrito em [docs/ia.md](docs/ia.md).
